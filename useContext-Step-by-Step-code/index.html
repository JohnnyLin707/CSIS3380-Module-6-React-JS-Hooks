useContext examples

useContext lets a component read a value that a parent provides, without passing props through every level. Open this page with Live Server, then work through the examples in order.

  • 01 · The problem: prop drillingA name typed at the top is passed through a component that does not need it.
  • 02 · The fix: create, provide, consumeThe same app with a context. The middle component no longer passes anything on.
  • 03 · Sharing a value and a functionA theme context holds the current theme and a toggle that any component can call.
  • 04 · A provider component and a custom hookAuthProvider wraps its children; useAuth() gives any component the user, login and logout.
