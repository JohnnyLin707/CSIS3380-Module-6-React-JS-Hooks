useRef examples

useRef keeps a value between renders without causing a re-render, or points at a DOM element. Open this page with Live Server, then work through the examples in order.

  • 01 · Reaching a DOM elementA ref points at an input, so a button can focus it or select its text.
  • 02 · A ref remembers, but does not re-renderTwo counters side by side: one in state, one in a ref. Watch the Console.
  • 03 · Keeping a timer idA stopwatch stores its interval id in a ref, so Stop and Reset can clear it.
  • 04 · Remembering the previous valueAn effect copies each render's value into a ref, so the next render can show it.
  • 05 · Passing a ref through your own componentforwardRef lets a parent focus an input that lives inside a child component.
